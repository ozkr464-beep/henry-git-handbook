# Git Developer Handbook

Guía web de referencia sobre Git y GitHub, desarrollada como proyecto académico durante el bootcamp Full Stack Part Time de Soy Henry.

El objetivo es practicar los fundamentos de control de versiones, comprender los comandos esenciales de Git y documentar la evolución de un proyecto mediante commits.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code

## Contenido del proyecto

La guía incluye:

- Introducción al control de versiones con Git.
- Explicación de los comandos `git init`, `git status`, `git add` y `git commit`.
- Consulta del historial mediante `git log`.
- Gestión básica de repositorios remotos con `git remote`, `git push` y `git pull`.
- Diseño adaptable a pantallas móviles y de escritorio.

## Estructura

## Cómo utilizarlo

1. Descarga o clona el repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en tu navegador o utiliza Live Server.
4. Consulta las explicaciones y ejemplos de comandos Git.

No requiere instalar dependencias adicionales para visualizar el sitio.

## Historial de desarrollo

El proyecto fue construido mediante cuatro etapas:

1. Creación de la estructura HTML inicial.
2. Incorporación de la guía de comandos Git.
3. Aplicación de estilos CSS y diseño responsive.
4. Documentación del proyecto mediante README.

## Aprendizajes

Durante esta actividad practiqué la inicialización de repositorios, selección de archivos mediante staging, creación de commits descriptivos y consulta del historial de versiones.
