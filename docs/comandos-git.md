
# Comandos esenciales de Git

## Inicializar un repositorio

```bash
git init
```

## Consultar el estado

```bash
git status
```

## Consultar el estado resumido

```bash
git status --short
```

## Preparar un archivo

```bash
git add index.html
```

## Registrar cambios

```bash
git commit -m "docs: agregar documentacion"
```

## Consultar el historial

```bash
git log --oneline
```

## Consultar archivos rastreados

```bash
git ls-files
```

## Revisar cambios preparados

```bash
git diff --cached
```

## Publicar commits

```bash
git push
```
