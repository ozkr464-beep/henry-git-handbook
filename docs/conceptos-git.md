
# Conceptos básicos de Git

## Repositorio
Es el proyecto controlado por Git, junto con su historial de versiones.

## Working Directory
Es el espacio donde creamos y modificamos nuestros archivos.

## Untracked
Archivo que Git todavía no está rastreando.

## Tracked
Archivo que Git ya conoce y puede supervisar.

## Staging Area
Área donde preparamos los cambios que formarán parte del próximo commit.

## Commit
Registro de un estado del proyecto dentro del historial de Git.

## Branch
Rama que permite mantener una línea de desarrollo.

## GitHub
Plataforma donde podemos alojar repositorios Git y colaborar con otros desarrolladores.
