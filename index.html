Git Developer Handbook

Mi guía de Git y GitHub para aprender control de versiones.

¿Qué es Git?

Git es un sistema de control de versiones que permite registrar cambios y consultar el historial de un proyecto.

Comandos esenciales de Git

git init

Inicializa un repositorio Git en la carpeta actual. 

git init

git status

Muestra el estado de los archivos del repositorio. 

git status

git add

Prepara archivos para incluirlos en el próximo commit. 

git add index.html

git commit

Registra los cambios preparados en el historial local. 

git commit -m "feat: agregar contenido"

git log

Permite consultar el historial de commits. 

git log --oneline

git remote

Permite configurar y consultar las conexiones con repositorios remotos. 

git remote -v

git push

Envía los commits locales al repositorio remoto. 

git push

git pull

Obtiene e integra cambios de un repositorio remoto en la rama local. 

git pull
